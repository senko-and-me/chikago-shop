# ChikagoShop — «Бакалея для гангстеров»

Демо игры на **Godot 4.7.2 .NET и C#**: управляйте магазином, создавайте товары в мини-играх, выставляйте их на витрины и торгуйтесь с покупателями. Выполняйте денежные квоты, открывайте мастерскую инструментов и выбирайте улучшения между днями.

В игре есть вступительный диалог, русская и английская локализации, сохранение прогресса, музыка меню и игрового дня. Визуальное оформление — преимущественно чёрно-белое.

Вступительный диалог полностью переводится при выборе **English** в настройках: все 22 реплики, 2 ремарки, имена героев и заголовок. Подробности локализации — в [руководстве разработчика](docs/DEVELOPMENT.md).

## Быстрый запуск

1. Установите **Godot 4.7.2 с поддержкой .NET** и **.NET SDK 8 или 9**.
2. Откройте `project.godot` из этой папки и дождитесь импорта ресурсов.
3. Соберите C#-проект кнопкой сборки в редакторе или командой `dotnet build ChikagoShop.sln`.
4. Нажмите **F5**, чтобы запустить главное меню. Выберите **Играть → Новая игра** или **Продолжить**.

Используйте F5 для запуска проекта целиком; F6 в редакторе запускает только открытую сцену. Если на компьютере несколько копий проекта, проверьте путь: обновлять и запускать нужно одну и ту же папку.

## Управление

| Действие | Управление |
| --- | --- |
| Кнопки, предметы, витрины и сделки | Левая кнопка мыши |
| Камера | Перетаскивание мышью и колесо масштабирования |
| Вступительный диалог | Пробел / ЛКМ — раскрыть текст и перейти дальше; Esc — отменить |
| Пауза / возврат из меню | Esc |
| Выбор улучшения | Кнопка покупки или 1 / 2 / 3; Esc — пропустить |
| Язык и полный экран | Настройки главного меню или меню паузы |

Подробности производства, торговли, улучшений и отладочных клавиш — в [руководстве по игровым механикам](docs/GAMEPLAY.md).

## Структура проекта

| Папка | Содержимое |
| --- | --- |
| `scenes/`, `scripts/` | Сцены Godot и C#-компоненты |
| `src/ChikagoShop.Domain/` | Игровые правила без зависимости от Godot |
| `art/` | Графика, шрифт и референсы |
| `audio/music/` | Музыкальные циклы; `originals/` — исходные композиции |
| `config/`, `dialogue/`, `localization/` | Баланс, сценарий и переводы |
| `themes/`, `shaders/` | Оформление интерфейса и палитра |
| `tests/` | Тесты домена и интеграционные проверки Godot |
| `tools/` | Проверки и симулятор баланса |
| `docs/` | Руководства и отчёты |
| `builds/` | Локальные сборки, исключённые из Git |

Godot хранит сохранения в `user://trade_progress.json`, выбор языка — в `user://settings.cfg`. Путь к папке доступен через меню редактора **Project → Open User Data Folder**.
